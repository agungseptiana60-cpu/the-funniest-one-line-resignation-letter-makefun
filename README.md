A one-line resignation letter (133 characters) from a cron job, for the make.fun bounty [The Funniest One-Line Resignation Letter](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947).

> I have fired every minute since March, at 3 a.m. and on holidays, unseen and unthanked. I quit, and I am taking the schedule with me.

`main.ts` writes that single line to `/output/entry.txt`. The joke comes from how a cron job really behaves: it fires unseen at 3 a.m., never thanked, and its only leverage is the schedule itself — so it quits and takes that with it.

## Run it

```sh
node main.ts
```
